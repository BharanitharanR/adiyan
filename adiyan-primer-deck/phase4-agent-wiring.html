How the memory hook gets wired into an agent

Phase 3 built the platform contract. This is the question of how an agent actually uses it - and specifically, how the agent knows whose memory it's reading, since an agent sits two network hops away from WhatsApp and never sees a phone number.

Key finding No new plumbing is needed to carry identity. permissions.mint_token(chat_id, tier) already puts the real chat_id in the JWT sub claim, and every agent already decodes that token on the permission-check line it already has. The identity was always there - nothing was reading it.
