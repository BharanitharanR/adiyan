# What is Adiyan — video script

Rough length: ~2 minutes read aloud at a normal pace. Beats are marked so you can pause or cut to a visual (the website's diagrams work well here).

---

**Hook**

"Adiyan" means "your humble servant" in Tamil. That's exactly what it is — an AI agent that runs on *your* machine, not someone else's cloud.

**The problem**

Every AI tool today works the same way: your data goes to someone else's server, gets processed there, and comes back. You never really own the thing you're using — you're renting it, one API call at a time.

**What Adiyan is**

Adiyan flips that. It's an AI agent harness you install on your own computer. Out of the box, it comes with seven working agents already wired together — one that routes your messages, one that remembers what you've told it, one that runs scheduled jobs, one that reads whole documents, and more. You talk to all of it through WhatsApp, so there's no new app to learn.

*(Cut to the "out of the box" diagram — Orchestrator in the middle, the six agents around it.)*

**Four things it does**

1. **It's an agent harness.** Everything above — install it, and it's already working.
2. **It reads to you.** Adiyan Reader takes any book you give it, reads you one page a night as a voice note, and quizzes you the next day on what you actually remember.
3. **It's extendable.** If you know a bit of Python, you can add your own agent, and the mesh finds it automatically — no routing code to write.
4. **It's part of a community, if you want.** If your machine is ever too busy or too small for a request, Adiyan can ask a peer's Adiyan for help — only when you opt in, never by default.

**The pitch, one line**

The cloud centralizes AI. Adiyan distributes it. It's not another AI subscription — it's a different way to own one.

**Close**

If that sounds like something you want running on your own machine, the next video shows exactly how to install it — it takes one command.
