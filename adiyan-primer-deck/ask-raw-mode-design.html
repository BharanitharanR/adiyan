Adiyan Primer Deck / ask() raw mode

Adiyan · platform capability · proposal

Teaching ask() to speak Orpheus's language

Right now Orpheus TTS calls Ollama directly, bypassing every platform benefit every other agent gets for free - logging, dashboard-editable stage config, and (critically) the memory-context hook. Here's exactly what closes that gap.

Confirmed gap mesh/adiyan_reader/tts.py's _generate_tokens() builds its own httpx.AsyncClient straight to Ollama's /api/generate - it has never once passed through AdiyanAgent.ask(), so it gets none of tonight's platform work: not the central log, not tiered prompts, not stage config from the dashboard.

1. What ask() needs to learn

One new parameter, checked before the existing four branches - raw mode is always local, same class as schema/tools/image.



  
2. Where the logic actually moves from

  
tts.py's own _generate_tokens() body relocates almost unchanged - this isn't new logic, it's the same raw-streaming call finding a shared home.

  


  

    The one guard that matters most: raw mode must be added to the SAME exclusion list as schema/image_b64 for memory-context prepending. Without it, ask() would inject "What you know about this person:\n- ..." straight into the Orpheus prompt - and Orpheus, having no idea that text isn't meant to be read aloud, would literally vocalize your own stored facts at the start of every voice note. This is a real, concrete failure mode this design has to rule out on purpose, not something to notice after the fact.
  


  
3. What tts.py looks like afterward

  
One call, everything else in the file untouched.

  
async def _generate_tokens(prompt: str, cfg, max_tokens: int) -> List[str]:
    return await _agent.ask(
        prompt, stage='synthesize_speech', model=cfg['model'],
        raw=True, num_predict=max_tokens, top_p=cfg.get('top_p', 0.9),
        repetition_penalty=cfg.get('repetition_penalty', 1.1),
    )

  
Every other function in tts.py - chunking, SNAC decode, WAV/Opus assembly - never changes. Only the one function that talks to Ollama does.
