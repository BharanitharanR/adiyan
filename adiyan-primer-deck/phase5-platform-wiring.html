3. What "zero code change" actually covers

  
Being honest about the boundary, not overselling it.

  

    

      
Read side - fully automatic

      
Every _agent.ask(...) call, in every skill, in every agent, gets the caller's known facts prepended before the LLM sees the prompt. No skill author does anything - it already goes through ask() today for every LLM call in the mesh.

    

    

      
Write side - deliberately manual

      
Deciding what counts as a fact worth recording from a skill's own outcome is domain judgment the platform can't guess generically. This stays one explicit memory_hook.record_fact(...) line per skill that wants to write - same as micro_habits already has today.
