Teaching Adiyan to hear Tamil voice notes

A voice note arrives on WhatsApp, gets turned into Tamil text, and a small Indic-language model answers - all running locally, no cloud calls. Here's exactly what that pipeline looks like, and the real test evidence behind each piece, before any of it gets wired into the live mesh.

Starting point: WhatsApp voice notes are currently invisible to Adiyan. openwa_receiver.py only recognizes image and document media types - a voice note (ptt) is silently dropped before it ever reaches the orchestrator. Nothing crashes; it just never arrives.

The pipeline

Four stages, three of them touching code that doesn't exist yet.

Real test evidence, not a guess

Sarvam-1 is a raw completion model, not a chat model - three live tests against the actual local model, step through them.

Why this matters for the build: a real WhatsApp voice note transcribes to a natural question, not a fill-in-the-blank sentence - test 2's exact shape. Left alone, sarvam-1 just echoes it back. The fix (test 3) is a few-shot கேள்வி: ... பதில்: ... wrapper, plus a stop sequence at the next கேள்வி: marker so it doesn't ramble into an invented follow-up conversation - the same fix already used for Orpheus's own hallucinated continuations earlier this session.

What's about to get built

In this order - each step is independently testable before the next one depends on it.

  1. 1Receiver: extend openwa_receiver.py to recognize ptt/audio messages (currently only image/document) and download the media the same way those two already do.
  2. 2Transcription module: a new function that shells out to the local whisper CLI with --language ta, returns the transcribed text - fails open (no crash) if Whisper errors, same convention as every other optional-enhancement step in this mesh.
  3. 3Stop-sequence support in ask(raw=True): _raw_ollama_stream() doesn't support a stop sequence yet - needed so sarvam-1 halts right after answering instead of inventing a follow-up exchange.
  4. 4Seeded few-shot prompt template: the கேள்வி: ... பதில்: ... wrapper, stored the same way add_emotion_tags's prompt is - dashboard-editable, not hardcoded.
  5. 5Wire into handle_message.run(): a new audio parameter, parallel to how image/document already branch - transcribe, then feed the transcribed text through the sarvam-1 step, then reply.
