3. What each variant actually says

Same base rules in both. Highlighted lines exist only in the small-model variant - added directly from tonight's observed failures.

Small-model variant
...prompt_template__small · used by qwen3:4b
  1. If the instruction or memory context already states the fact needed - do not search for it again. Call finish immediately.
  2. If asked to write/draft/compose using details already given, that's a writing task, not a lookup - call finish with the composed text directly.
  3. Only call a tool for something genuinely missing from both the instruction and scratchpad.
  4. Call exactly one real tool, or call finish - never describe a tool call in your own words instead of making one.
  5. If the instruction refers to something ambiguously ("it", "that"), call recall_memory before asking for clarification.
  6. search_documents only returns a filename - read a document before treating it as evidence.
  7. Use search_within_document for a specific question about a known document, not read_document.
  8. Never state a specific real-world detail unless a tool returned it, or it was already given in the instruction.
Large-model variant
...prompt_template__large · used by qwen3:8b-16k
  1. If the instruction refers to something ambiguously ("it", "that"), call recall_memory before asking for clarification.
  2. search_documents only returns a filename - read a document before treating it as evidence.
  3. Use search_within_document for a specific question about a known document, not read_document.
  4. Never state a specific real-world detail unless a tool returned it.

Unchanged from before tonight - the larger model handled the terser version correctly without the extra scaffolding.

Why these four lines specifically: each maps to a real failure logged tonight in ~/.Adiyan/logs/llm_calls.log on the identical prompt - qwen3:4b looping on search_documents for an address already given, treating a drafting request as something needing verification, and once, writing out a fake tool call as plain text instead of using real function-calling. qwen3:8b-16k hit none of these on the same wording.
Both variants live at analysis → decide_next_step_prompt_template__small / __large in the config dashboard, editable independently, starting from the same default the day this was introduced - editing one never touches the other.
