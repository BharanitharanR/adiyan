This generates the same skeleton as running python3 -m mesh.tools.bootstrap_agent locally, done here in your browser instead. Nothing is uploaded anywhere. The zip is built on your own machine, right now, in this tab.

Lowercase letters, digits, and underscores. Must start with a letter.

  • skills_catalog.py
  • skills/roll_dice.py
  • runtime_config.json
  • seed_config.json
  • README.md

Unzip it into your Adiyan repo's mesh/ directory, then run it with python3 -m mesh.<name>.server. It still has the example's dice-roll logic in it. Replace skills/roll_dice.py and skills_catalog.py with your own. The assigned port is picked from the name, not checked against what's actually running on your machine, so confirm it's free before starting the agent.
