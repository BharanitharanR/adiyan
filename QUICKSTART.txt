ADIYAN - ORCHESTRATOR QUICKSTART
================================

1. INSTALL DEPENDENCIES
   cd /Users/bharani/Desktop/aiAgentCompaction/Adiyan
   pip install -r requirements.txt

2. START SERVICES (in separate terminals)

   Terminal 1 - Start Ollama:
   ollama serve

   Terminal 2 - Start RabbitMQ (optional, system works without it):
   rabbitmq-server

   Terminal 3 - Start Adiyan Orchestrator:
   cd /Users/bharani/Desktop/aiAgentCompaction/Adiyan
   python main.py

3. ACCESS CONTROL PANEL
   Open: http://localhost:5001

   Dashboard shows:
   - 7 Agents (Parser, Validator, Router, LLM, Synthesizer, Storage, Publisher)
   - Enable/Disable each agent
   - Recent interactions
   - System logs
   - Live status

4. SEND MESSAGES

   Option A - Via WhatsApp (integrate with wa-echo-loop):
   "Register me in your coaching program"
   "Your question here" (for coaching)
   "Unregister me"

   Option B - Via cURL (testing):
   curl -X POST http://localhost:5000/api/test-message \
     -H "Content-Type: application/json" \
     -d '{
       "contact_name": "John",
       "lid": "1234567890",
       "message_body": "How do I improve my decision making?"
     }'

5. DATA STORAGE
   All data saved in: ~/.Adiyan/

   Files:
   - pipeline.json: Agent configurations
   - whitelist.txt: Registered users
   - interaction_history.jsonl: All messages and responses
   - orchestrator.log: System logs

6. CUSTOMIZATION

   UI Control Panel (Port 5000):
   - Toggle agents on/off
   - Change agent tools
   - View system settings
   - Monitor interactions

7. ARCHITECTURE

   Pipeline: Message → [7 Agents] → Response

   Stage 1: Parser Agent
   ├─ Extract contact name, LID, message content

   Stage 2: Validator Agent
   ├─ Check whitelist
   ├─ Detect registration/unregistration

   Stage 3: Router Agent
   ├─ Select persona
   ├─ Load system prompt

   Stage 4: LLM Agent
   ├─ Call Ollama with prompt
   ├─ Generate response

   Stage 5: Synthesizer Agent
   ├─ Format response
   ├─ Split into chunks

   Stage 6: Storage Agent
   ├─ Save to file
   ├─ Store in Qdrant (optional)

   Stage 7: Publisher Agent
   ├─ Send WhatsApp reply
   ├─ Publish events to RabbitMQ

TROUBLESHOOTING
===============

Q: "Cannot connect to Ollama"
A: Make sure ollama serve is running in a separate terminal

Q: "RabbitMQ connection failed"
A: RabbitMQ is optional - system works without it

Q: "WhatsApp replies not sent"
A: Integrate with wa-echo-loop service (see Integration section)

Q: "Control panel shows error"
A: Check ~/.Adiyan/orchestrator.log for details

INTEGRATION WITH WA-ECHO-LOOP
==============================

1. Update wa-echo-loop/app.js to publish messages to RabbitMQ

2. Change message handler from direct LLM to:
   rabbitmq.publish('adiyan', 'messages.incoming', {
     contact_name: contact.name,
     lid: msg.from.split('@')[0],
     message_body: msg.body,
     message_id: msg.id
   })

3. Subscribe to adiyan.reply events:
   rabbitmq.subscribe('adiyan', 'events.response_sent', (reply) => {
     msg.reply(reply.response)
   })
